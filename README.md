## 🚀 Featured project

### [Snip — Production-grade URL Shortener API](https://github.com/AfranUsmani/Snip)

A REST service in **Java 21 · Spring Boot 3** that generates random, **unguessable** short codes (links can't be enumerated), serves redirects via a **Redis cache-aside** layer, and supports custom aliases, QR codes, link expiry, and **async click analytics**. Ships with **Prometheus / Actuator** metrics, **OpenAPI/Swagger** docs, Docker Compose, GitHub Actions CI, and a full unit + integration test suite.

`Java 21` · `Spring Boot 3` · `Redis` · `PostgreSQL` · `Docker` · `Prometheus` · `GitHub Actions`
